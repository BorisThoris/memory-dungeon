# UI-004 - Profile save-trust panel

**Priority:** P2  
**Status:** Done  
**Maps to:** Save/profile trust refinement from product inspection.

## Evidence

The Profile screen already derived save-scope, cloud-sync, export/import, backup, and reset-boundary copy in `profile-summary`, but the rendered UI exposed the most important trust message as a footer sentence. That made cloud/save expectations easy to miss when reviewing profile state, especially on compact viewports.

## Acceptance criteria

- Profile presents save trust as a structured panel with readable per-topic rows.
- Cloud sync availability comes from the product feature gate unless a platform shell explicitly overrides it.
- Compact layouts keep labels, status chips, and descriptions readable without horizontal overflow.
- Focused component/shared tests cover the rendered panel and feature-gated cloud copy.
