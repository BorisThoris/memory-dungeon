# NGE-003 Shop And Run Economy

## Goal

Make shops a reliable route tool for keys, board control, and trait manipulation.

## Acceptance

- Shops can sell swap/row charges, reveal charges, keys, trait cleanses, and rerolls.
- Key-gated exits always have a reachable key/shop/master-key route.
- Shop stock is deterministic and route-aware.
- Tests cover insufficient funds, stock exhaustion, incompatible contracts, and softlock escape.
